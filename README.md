# 📇 Contact Management System

A simple and responsive Contact Management System built using **HTML, CSS, and JavaScript**.  
This project allows users to manage contacts directly in the browser using **localStorage**.


## ✨ Features

- ➕ Add new contacts (Name & Phone Number)
- 📋 View all saved contacts in a table format
- 🔍 Real-time search functionality
- 💾 Data persistence using browser localStorage
- 📱 Fully responsive UI (basic)

---

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Browser localStorage

---

## 📁 Project Structure
contact-management-system/

## ⚙️ How It Works

- User enters contact details
- JavaScript stores data in an array
- Data is saved in localStorage for persistence
- Contacts are dynamically displayed on screen
- Search filters contacts using JavaScript
